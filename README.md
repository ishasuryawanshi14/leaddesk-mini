# LeadDesk Mini

LeadDesk Mini is a full-stack lead management system built using **Next.js**, **Tailwind CSS**, and **Supabase**. It allows users to submit inquiries through a responsive landing page while providing an admin dashboard to manage and track leads efficiently.

---

##  Features

- Responsive Landing Page
- Lead Registration Form
- Client-side Validation
- Server-side Validation
- Supabase Database Integration
- Admin Login with Supabase Authentication
- Protected Admin Dashboard
- Search Leads
- Update Lead Status (New, Contacted, Closed)
- Logout Functionality

---

## Tech Stack

- Next.js
- React.js
- Tailwind CSS
- Supabase
- React Hook Form
- Zod
